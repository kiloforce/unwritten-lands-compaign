THE UNWRITTEN LANDS — CHARACTER CREATION APP

This is a self-contained offline character-creation/journal app for the Pathfinder campaign “The Unwritten Lands.”

Files: - index.html — open this in a browser to use the app. - The app stores the journal locally in the browser. - Backup Journal — saves a JSON backup. - Export for GM — creates a compact JSON package for the GM. - Download Spreadsheet — creates an Excel-compatible .xls workbook with separate worksheets for Character, Background Events, People, Places, Traits, Secrets, Mysteries, Revelations, Sessions, and Legacy.

The spreadsheet export is designed to be opened in Microsoft Excel and can be copied into the campaign GM Atlas workbook.

Pathfinder terminology used in the app: Ancestry, Heritage, Background, Class, Level, Key Ability, etc.

Campaign name: THE UNWRITTEN LANDS Tagline: Ordinary People. Extraordinary Pasts. A World Still Being Written.
